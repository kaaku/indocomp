# Indonesia merger bidding calculator

This app is a simple merger bidding calculator for the board game [Indonesia](https://boardgamegeek.com/boardgame/19777/indonesia) by [Splotter Spellen](https://www.splottershop.com/). It's designed to work well on mobile, so that each player can easily plan and execute their mergers.

The app is hosted at [https://kaaku.github.io/indocomp/](https://kaaku.github.io/indocomp/).
